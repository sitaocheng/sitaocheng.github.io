From Atomic to Composite: Reinforcement Learning
Enables Generalization in Complementary Reasoning

Sitao Cheng1, Xunjian Yin2, Ruiwen Zhou3, Yuxuan Li1, Xinyi Wang4, Liangming Pan5, William Yang Wang6, Victor Zhong1

1University of Waterloo  ·  2Duke University  ·  3National University of Singapore  ·  4Princeton University  ·  5Peking University  ·  6University of California, Santa Barbara

Contact: sitao.cheng@uwaterloo.ca · liangmingpan@pku.edu.cn · victor.zhong@uwaterloo.ca

Paper Code Data See how the data is built

TL;DR We build a contamination-free benchmark of synthetic biographies and find two things. (1) SFT on composite questions memorizes the seen reasoning paths and fails on unseen relations. (2) RL generalizes to unseen compositions, but only after the model learns the atomic skills: recalling facts from its weights and reading facts from the context.

Read the abstract

Does Reinforcement Learning (RL) merely amplify existing skills, or does it synthesize new ones? We study this question through Complementary Reasoning: the capability of integrating knowledge stored in model weights with novel information provided in context, a prerequisite for continual learning and retrieval-augmented generation. To avoid pre-training contamination, we construct a controlled semantic-synthetic dataset of biographies and decompose the capability into two atomic skills: Parametric Reasoning (retrieving facts encoded in model weights) and Contextual Reasoning (processing novel in-context information). We present two findings. First, models supervised directly on the composite task reach high accuracy on seen facts and reasoning paths (90%) but collapse on paths with unseen relations (18%), indicating that Supervised Fine-Tuning (SFT) relies on memorization rather than skill integration. Second, RL closes this generalization gap and acts as a behavioral synthesizer rather than a mere amplifier, but only under a strict prerequisite: it composes new strategies only when the base model has first acquired the independent atomic skills via SFT. These results suggest that decoupled atomic training followed by RL offers a scalable path to complex and novel reasoning.

Benchmark

One knowledge graph, three reasoning types

Every fact comes from a synthetic knowledge graph, so no fact appears in pre-training data. Where a fact lives decides which skill a question needs: memory facts are trained into the weights, and context facts are given in the prompt.

Findings

RL composes skills, if the atomic skills come first

SFT memorizes rather than generalizes

SFT directly on 181k complementary questions reaches 90.3% on seen paths but only 18.4% when a relation is new. SFT on the atomic skills alone does not compose them either. Learning each skill does not teach the model to combine them.

Atomic-first wins on unseen relations at every data split

We split the composite data into an SFT share and an RL share. Composite-first runs SFT on the SFT share, and atomic-first runs SFT on the atomic data instead. Both recipes then run the same RL on the RL share. At every split, RL adds 18 to 48 points to atomic-first and at most 12 points to composite-first.

RL needs both atomic skills

We give the same RL (12.8k complementary questions) to models with different SFT. Models that learned only memory facts or only context reading gain little, and so do models with a small dose of composite SFT. Only the model with both atomic skills gains strongly.

Further SFT is no substitute for RL

From the same atomic model and the same 12.8k composite questions, further SFT gives the best accuracy on seen paths (75.5% vs. 71.3% for RL). On unseen relations RL leads, with 42.6% against 35.7% for SFT and 34.6% for LoRA.

Analysis

A synthesizer on atomic skills, an amplifier without them

If RL only amplified behavior the SFT model already has, sampling the SFT model enough times would find the same answers, and the pass@k curves would meet. They meet only for the composite-first model.

RL moves the failure point later

Without atomic-first RL, most errors happen early, when the model reads the context. After atomic-first RL, 70% of the remaining errors are in recalling memory facts, and they happen near the end of the chain. RL fixes the bridging between context and memory.
